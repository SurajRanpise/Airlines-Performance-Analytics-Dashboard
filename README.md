# ✈️ High Cloud Airlines Performance Analytics

> **End-to-End Power BI Business Intelligence Project**  
> Transforming historical US airline operational data into actionable business insights using **Power BI, Power Query, DAX, and Star Schema Data Modeling**.

---

## 📌 Project Overview

The **High Cloud Airlines Performance Analytics** project is an end-to-end Business Intelligence solution designed to analyze historical US airline operational data (2008–2013).

The dashboard provides interactive insights into airline performance, passenger traffic, flight operations, load factor, carrier performance, freight transportation, route analysis, and geographic trends, enabling data-driven business decision-making.

---

## 🎯 Business Objectives

- Analyze airline operational performance.
- Measure seat utilization using **Load Factor**.
- Compare carrier performance.
- Identify the busiest routes.
- Analyze passenger travel trends.
- Evaluate freight transportation.
- Compare weekday vs weekend operations.
- Analyze flights across different distance groups.
- Build an interactive executive dashboard for business users.

# 💡 Key Business Insights

- Overall Load Factor remained **76.80%**, indicating efficient seat utilization.
- More than **187 Million passengers** travelled across **2.80 Million flights**.
- **Southwest Airlines** operated the highest number of flights.
- Passenger demand peaked during **July**.
- **Federal Express** transported the highest freight volume.
- Approximately **71% of flights** operated during weekdays.
- The **United States** had the highest number of operating airlines.
- The **8500–8999 Miles** distance interval recorded the highest Load Factor among the displayed groups.
